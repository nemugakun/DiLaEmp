# Bibliotecas Third-Party

Este proyecto utiliza software de código abierto third-party.

## Componentes Radzen Blazor

Este proyecto utiliza componentes Radzen Blazor (`Radzen.Blazor`) para el diseño de componentes gráficos como calendarios, periodos de tiempo y fechas.

Los componentes Radzen Blazor son distribuidos bajo la licencia MIT.

Los derechos y términos y condiciones de la licencia para los componentes de Radzen Blazor están disponibles en la [página oficial de Radzen Blazor](https://www.radzen.com/terms).
